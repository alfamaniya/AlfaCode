# آلفاکد (AlfaCode)

آلفاکد یک محیط سبک برای نوشتن و اجرای نمونه‌های HTML، CSS و JavaScript در مرورگر است. رابط کاربری با HTML، CSS و JavaScript خام ساخته شده و کتابخانه‌های ویرایشگر را از نسخه‌های محلی داخل مخزن بارگذاری می‌کند؛ برای استفاده به CDN یا نصب بسته‌های npm نیاز ندارد.

## درخت مخزن

```text
AlfaCode/
├── index.html                         # ساختار صفحه، ابزارها و آیکون‌های SVG
├── style.css                          # ورودی اصلی و ترتیب بارگذاری CSS
├── css/
│   ├── theme.css                      # متغیرها، پایه و قواعد عمومی
│   ├── shell.css                      # سربرگ، نوارها و چیدمان صفحه
│   ├── editor.css                     # ویرایشگر و پیش‌نمایش
│   ├── components.css                 # جداکننده و پیام‌های موقت
│   └── responsive.css                 # قواعد نمایشگرهای کوچک
├── js/
│   ├── ui/
│   │   └── layout.js                  # نوارهای کناری، اندازه‌بندی و تب‌ها
│   └── editor/
│       ├── defaults.js                # محتوای پیش‌فرض نمونه
│       ├── html-import.js             # پردازش و تفکیک HTML/CSS/JS
│       ├── preview-document.js        # ساخت سند پیش‌نمایش و حالت انتخاب بصری
│       ├── engines.js                 # اتصال موتورهای Monaco و CodeMirror
│       ├── visual-inspector.js        # تعاملات ویرایشگر بصری
│       └── controller.js              # وضعیت و هماهنگ‌سازی قابلیت‌های ویرایشگر
├── README.md                          # راهنمای پروژه
└── editors/
    ├── codemirror6/
    │   ├── codemirror.js              # بستهٔ آمادهٔ CodeMirror 6 برای مرورگر
    │   ├── build-entry.js              # نقطهٔ ورود برای ساخت مجدد بسته
    │   ├── README.md                  # توضیحات CodeMirror
    │   └── licenses/
    │       ├── THIRD_PARTY_NOTICES.txt # مجوزهای وابستگی‌های همراه
    │       ├── @codemirror/
    │       ├── @lezer/
    │       ├── @marijn/
    │       ├── codemirror/
    │       ├── crelt/
    │       ├── style-mod/
    │       └── w3c-keyname/
    └── monaco/
        ├── LICENSE                    # مجوز Monaco Editor
        ├── README.md                  # توضیحات و شیوهٔ بارگذاری Monaco
        └── vs/
            ├── loader.js              # بارگذار AMD موناکو
            ├── editor.js              # نقطهٔ ورود ویرایشگر
            ├── editor/                # کدهای اصلی ویرایشگر
            ├── language/              # سرویس‌ها و قابلیت‌های زبان
            ├── basic-languages/       # تعریف زبان‌ها و حالت‌های پایه
            ├── assets/                # منابع جانبی
            ├── nls/                   # منابع پیام‌ها و بومی‌سازی
            ├── *.worker-*.js          # Workerهای زبان‌ها
            └── *-<hash>.js            # بسته‌های زبان و قابلیت‌های همراه
```

> پوشهٔ `editors/monaco/vs/` شامل فایل‌های توزیع‌شدهٔ Monaco است؛ برای خوانایی، همهٔ بسته‌های زبان و فایل‌های حجیم آن جداگانه در درخت بالا فهرست نشده‌اند.

## قابلیت‌ها

- ویرایش جداگانهٔ HTML، CSS و JavaScript در تب‌های مستقل.
- انتخاب بین دو موتور ویرایشگر Monaco و CodeMirror 6.
- نمایش زندهٔ خروجی در پیش‌نمایش ایزوله‌شده با `iframe` و sandbox.
- ذخیرهٔ خودکار کدها، موتور انتخاب‌شده و برخی تنظیمات چیدمان در `localStorage` مرورگر.
- واردکردن فایل HTML و انتقال محتوای `<style>` و `<script>` به تب‌های مربوط.
- چسباندن سند کامل HTML در ویرایشگر HTML یا کشیدن فایل روی آن؛ سبک‌ها و اسکریپت‌های درون‌خطی به تب‌های جدا منتقل می‌شوند.
- دانلود خروجی به‌شکل یک فایل HTML، جست‌وجو، واگردانی و انجام دوباره.
- بازکردن پیش‌نمایش در پنجره‌ای جداگانه.
- انتخاب عنصر در پیش‌نمایش از طریق ابزار ویرایش بصری و مرور گروه‌های تنظیمات CSS.
- چیدمان قابل تغییر، نوارهای کناری جمع‌شونده و تنظیم بخش‌های صفحه.

## راه‌اندازی

برای بارگذاری مطمئن فایل‌های محلی و Workerهای Monaco، پروژه را با یک وب‌سرور محلی اجرا کنید. اجرای مستقیم `index.html` با نشانی `file://` ممکن است به‌دلیل محدودیت‌های مرورگر درست کار نکند.

در ترمینال به پوشهٔ `AlfaCode` بروید و اجرا کنید:

```bash
python -m http.server 8000
```

سپس نشانی زیر را در مرورگر باز کنید:

```text
http://localhost:8000
```

اگر سرور را از پوشهٔ والد `AlfaCode` اجرا کرده‌اید، از این نشانی استفاده کنید:

```text
http://localhost:8000/AlfaCode/
```

Python باید در دسترس ترمینال باشد. نصب وابستگی یا فرایند build لازم نیست.

## استفاده

1. در تب‌های HTML، CSS و JS کد بنویسید؛ تغییرات پس از مکث کوتاه در پیش‌نمایش اعمال می‌شوند.
2. برای بازکردن نمونه در پنجره‌ای جدا، دکمهٔ **Open preview in new window** را بزنید. اگر پنجره باز نشد، مجوز popup را برای این صفحه فعال کنید.
3. برای واردکردن کد، فایل HTML را با دکمهٔ Import انتخاب کنید یا روی سطح ویرایشگر HTML بکشید. محتوای `<style>` و `<script>` درون‌خطی از HTML جدا می‌شود. چسباندن یک سند کامل HTML در ویرایشگر HTML نیز همین جداسازی را انجام می‌دهد.
4. دکمهٔ **Visual edit** را بزنید، سپس عنصری را در پیش‌نمایش انتخاب کنید. گروه‌ها در حال حاضر برای دسته‌بندی تنظیمات هستند؛ کنترل‌های تغییر جزئیات CSS در این گروه‌ها هنوز پیاده‌سازی نشده‌اند.
5. کدها و موتور ویرایشگر در `localStorage` همان مرورگر ذخیره می‌شوند. دکمهٔ Factory reset محتوای کد را به نمونهٔ پیش‌فرض برمی‌گرداند و Clear all tabs هر سه تب را خالی می‌کند.

## ساختار کد

- **`index.html`**: اجزای رابط، دکمه‌ها، پنل‌ها، پیش‌نمایش، نمادهای SVG داخلی و ترتیب بارگذاری فایل‌ها.
- **`style.css` و `css/`**: ورودی سبک‌ها و فایل‌های موضوعی برای پوسته، چیدمان، ویرایشگر، مؤلفه‌ها و واکنش‌گرایی.
- **`js/ui/layout.js`**: مدیریت نوارهای کناری، جداکنندهٔ قابل‌تغییر و تب‌های صفحه.
- **`js/editor/defaults.js`**: کد پیش‌فرضی که هنگام شروع یا بازنشانی استفاده می‌شود.
- **`js/editor/engines.js`**: راه‌اندازی و یکسان‌سازی رابط دو موتور ویرایشگر.
- **`js/editor/html-import.js`**: جداسازی محتوای HTML، CSS و JavaScript هنگام واردکردن یا چسباندن سند کامل.
- **`js/editor/preview-document.js`**: ساخت سندی که در پیش‌نمایش اجرا می‌شود و اسکریپت انتخاب بصری داخل آن.
- **`js/editor/visual-inspector.js`**: حالت انتخاب عنصر و پیمایش گروه‌های تنظیمات بصری.
- **`js/editor/controller.js`**: هماهنگی وضعیت و رویدادهای ویرایش، ذخیره‌سازی، Import/Export و پیش‌نمایش.
- **`editors/`**: توزیع‌های محلی و مستندات دو موتور ویرایشگر. فایل‌های وابستگی و مجوزهای همراه CodeMirror در `editors/codemirror6/licenses/` قرار دارند.

فایل‌های CSS و JavaScript به‌صورت محلی و با ترتیب مشخص در `index.html` بارگذاری می‌شوند؛ نیازی به bundler، ماژول‌لودر یا بارگذاری پویای قطعه‌های HTML نیست.

## مجوزها

مجوزهای توزیع‌های ویرایشگر و وابستگی‌های همراه در فایل‌های داخل پوشهٔ `editors/` ثبت شده‌اند. برای جزئیات به `editors/monaco/LICENSE` و `editors/codemirror6/licenses/THIRD_PARTY_NOTICES.txt` مراجعه کنید.
